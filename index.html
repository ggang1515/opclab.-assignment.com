모델과 적용 범위

기본 모델은 5×5 격자 가중치 배열이며 [1,4,6,4,1]의 외적을 256으로 나눕니다. 모든 가중치 합은 1이고 중심값은 36/256, 적용 범위는 각 축 ±2칸(7nm)입니다. 이는 교육용으로 선택한 배열이며 과제 지정 수치나 측정된 광학 PSF가 아닙니다. σ는 배열 모드에 적용하지 않습니다. 비교용 Gaussian 모드에서는 교육용 이진 투과 마스크를 2D Gaussian 커널로 합성곱합니다. σ 단위는 격자이며 1 grid = 3.5 nm입니다. 각 축 ±ceil(4σ)에서 절단하고 커널 합을 1로 정규화합니다. 영상별 최대값 정규화는 하지 않습니다.

격자 중심 샘플링, 마스크 밖은 0, 고정 단위 dose입니다. I ≥ threshold인 영역을 현상 패턴으로 정의하며 음성 레지스트의 개념적 규칙으로 임계값 이상은 남고 미만은 제거된다고 가정합니다. 실제 재료 반응은 모델링하지 않습니다. 위상·회절·NA·파장·공정 보정은 포함하지 않아 실제 제조 예측에 적용할 수 없습니다.

자동 OPC는 최대 10회 양방향 셀 탐색과 초기 5회 인접 셀 쌍 탐색을 수행합니다. 불일치 셀 수 감소를 우선하고, 불일치가 같을 때는 노광량과 목표 이진 영상 사이의 제곱 오차가 감소하는 변경도 허용하여 임계값 정체를 완화합니다. 추가하는 셀은 기존 마스크에 변으로 연결되어야 하며, 4방향 연결 성분 수가 바뀌는 변경(고립 조각 생성, 패턴 단절·병합)은 거부합니다. 따라서 분리된 보조 패턴을 생성하지 않는 제한된 OPC입니다. 최소 선폭·간격 등 제조 규칙을 모두 검사하는 것은 아닙니다. 탐색 범위는 목표 주변 ±ceil(4σ) 격자입니다. 최종 현상 오차가 초기보다 크면 초기 마스크를 유지합니다. 전역 최적해나 개선을 보장하지 않습니다. IoU와 오차는 이 격자의 목표 대비 현상 패턴을 비교합니다.

100×100 작업 영역은 MVP의 편집 범위이며 과제 셀의 실제 크기가 아닙니다. 예제는 임의 교육용이며 지정 표준셀과 무관합니다.
